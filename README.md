# sage-ai

Навчальний вебсайт: лендінг ШІ-асистента.

## Сторінки
- `index.html`: головна (можливості, як це працює, FAQ)
- `pricing.html`: тарифи (таблиця)
- `register.html`: реєстрація (форма)

## Технології
HTML5, CSS3 (flexbox, grid, медіазапити, анімації), без JavaScript і фреймворків.

## Запуск
Відкрийте `index.html` у браузері.
